157: ### 2.2 Missing Field Handling & Imputation Pipeline
158: In the raw data, $1,087$ F70 entries and $731$ G60 entries lack `Feedback Type`, and many lack `Vfc Category`. We resolve this deterministically:
159: 1. **Length & Quality Filter**: Records with raw text $< 12$ characters or non-informative text (`"Good"`, `"N/A"`) are tagged as `Low-Signal` and excluded from core clustering.
160: 2. **Zero-Shot Heuristic Classifier**:
161:    * Evaluates text syntax and vocabulary:
162:      * *Praise keywords* (`"love"`, `"great"`, `"smooth"`, `"pleased"`) $\to$ `Feedback Type: Likes`.
163:      * *Ergonomic/friction phrases* (`"hard to find"`, `"took time to figure out"`, `"complicated"`, `"distracting"`) $\to$ `Feedback Type: Difficult to Use`.
164:      * *Failure/bug phrases* (`"glitch"`, `"broke"`, `"freezes"`, `"doesn't connect"`, `"error"`) $\to$ `Feedback Type: Defect`.
165:      * *Desire/request phrases* (`"wish"`, `"would be nice"`, `"needs"`, `"should offer"`) $\to$ `Feedback Type: Wants`.
166: 3. **Category Imputation**: For `no_class_found` or missing categories, match against an automotive ontology regex dictionary (e.g., `["screen", "display", "touch", "menu", "idrive"]` $\to$ `Touch screen, operation`).
167: 4. **Honesty Tagging**: Records with imputed fields are flagged `is_imputed = 1`. If a derived requirement relies heavily on imputed rows, its **Evidence Confidence Index** is penalised and flagged to the PM.

182: ## 3. Algorithmic Engines
183: 
184: ### 3.1 Explainable Multi-Factor Prioritization Model
185: Prioritization scores must be mathematical, reproducible, and explainable:
186: 
187: $$\text{Priority Score} = \frac{\left( \text{Customer Value} \times W_{\text{CV}} \right) + \left( \text{Market Volume} \times W_{\text{MV}} \right) + \left( \text{Strategic Fit} \times W_{\text{SF}} \right)}{\text{Implementation Complexity} \times W_{\text{IC}}}$$
188: 
189: #### Factor Calculation:
190: * **Customer Value ($1.0 - 10.0$)**:
191:   $$\text{Customer Value} = \min\left(10, \; \left( \log_2(\text{Signal Count} + 1) \times 1.8 \right) + \text{Severity Bonus} + \text{Kano Weight}\right)$$
192:   * *Severity Bonus*: Defect ($+2.0$), Difficult to Use ($+1.5$), Wants ($+1.0$).
193:   * *Kano Weight*: Must-Have ($+2.5$), Performance ($+1.5$), Delighter ($+1.0$).
194: * **Market Volume Factor ($1.0 - 10.0$)**:
195:   * Directly computed from `sales_volumes.xlsx` addressable 2030 forecast for targeted regions.
196:   * Normalizes the combined addressable volume: $V_{\text{target}} / V_{\text{max\_fleet}} \times 10.0$.
197: * **Strategic Fit ($1.0 - 10.0$)**:
198:   * Evaluates alignment with BMW Group strategic pillars: Neue Klasse platform readiness, circular sustainability, software-defined vehicle OTA, and premium brand perception.
199: * **Implementation Complexity ($1.0 - 5.0$)**:
200:   * Level 1: Minor Software OTA / UI adjustment
201:   * Level 2: Existing sensor/module calibration
202:   * Level 3: Interior trim / minor hardware packaging change
203:   * Level 4: New subsystem / supplier integration
204:   * Level 5: Major structural / platform architecture redesign
205: 
206: ### 3.2 The Trustworthy AI & Uncertainty Radar ("We Reward Honesty")
207: Every requirement carries an **Evidence Confidence Index (ECI)**:
208: 
209: $$\text{ECI} = \left( 0.4 \times C_{\text{volume}} \right) + \left( 0.3 \times C_{\text{source\_purity}} \right) + \left( 0.3 \times C_{\text{survey\_correlation}} \right)$$
210: 
211: * $C_{\text{volume}}$: Scaled based on sample size ($> 50$ citations = $1.0$, $20-50$ = $0.7$, $< 20$ = $0.4$).
212: * $C_{\text{source\_purity}}$: Ratio of raw ground-truth feedback vs. imputed rows ($1.0 - \text{Imputed Ratio}$).
213: * $C_{\text{survey\_correlation}}$: Agreement with quantitative customer study deltas ($1.0$ if backed by survey score drop, $0.5$ if neutral, $0.2$ if unmeasured).
214: 
215: #### Regional Conflict Detection Algorithm:
